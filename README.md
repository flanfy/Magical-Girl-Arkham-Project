# Magical Girl Arkham Project

A collection of ~75 custom investigators for **Arkham Horror: The Card Game** based on characters from the Magical Girl Raising Project light novel series, designed for use with [arkham.build](https://arkham.build).

---

## How to Use

### Deckbuilding (arkham.build)

Deckbuilding and image gallery
- In Arkham.build, go to settings -> fan-made content -> import from URL -> paste [https://raw.githubusercontent.com/flanfy/AHLCG-Fathomless-Sea-Investigator-Expansion/refs/heads/main/FathomlessSea.json](https://raw.githubusercontent.com/flanfy/Magical-Girl-Arkham-Project/refs/heads/main/MGRPArkham.json)

The custom investigators will now be available in your arkham.build collection.

### Importing decks into Tabletop Simulator

1. In TTS, go to **Downloadable Content → Fan-made Player Cards**
2. Find **Magical Girl Arkham Project** and click **Download**
3. Place the MGAP object in the **Additional Cards** box

---

## ⚠️ Known Issues

- **Unusual deckbuilding restrictions:** arkham.build may suggest cards that some investigators should not have access to due to non-standard deckbuilding rules. Please double-check that your deck is legal before playing.
